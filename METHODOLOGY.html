Embedding Generation
Convert documents into vector representations (embeddings) that databases can search

A Dense Embeddings (Text)

  • Model: sentence-transformers/all-MiniLM-L6-v2
  • Dimensions: 384
  • Purpose: Semantic similarity (understands meaning)
  • Process: Extract text → Encode → 384-dim vector
  • Applied to: PDFs and Word documents
from sentence_transformers import SentenceTransformer model = SentenceTransformer('all-MiniLM-L6-v2') text = extract_text_from_pdf('policy.pdf') vector = model.encode(text) # [384 floats]

B Sparse Embeddings (BM25)

  • Algorithm: BM25 (Best Matching 25)
  • Dimensions: Variable (vocabulary size)
  • Purpose: Keyword matching (exact terms)
  • Process: Tokenize → TF-IDF weights → Sparse vector
  • Applied to: PDFs and Word documents
from pymilvus.model.sparse import BM25EmbeddingFunction bm25 = BM25EmbeddingFunction() tokens = tokenize(text) sparse_vector = bm25.encode(tokens) # {word_id: weight, ...} - only non-zero

C Image Embeddings (CLIP)

  • Model: CLIP (clip-ViT-B-32)
  • Dimensions: 512
  • Purpose: Visual similarity (image content)
  • Process: Load image → Vision encoder → 512-dim vector
  • Applied to: PNG images only
from sentence_transformers import SentenceTransformer clip = SentenceTransformer('clip-ViT-B-32') img = Image.open('damage.png') vector = clip.encode(img) # [512 floats]
Embedding Stats:
• Dense vectors: 300 documents × 384 dimensions = 115,200 floats
• Sparse vectors: 300 documents × ~1000 non-zero terms = ~300,000 entries
• Image vectors: 50 images × 512 dimensions = 25,600 floats
• Processing time: ~30 seconds for all embeddings

Quality Benchmarking (Retrieval Accuracy)
Measure how accurate the search results are (not just how fast)

A Ground Truth Creation

  • Method: Policy type similarity scoring
  • Relevance scale: 0 (irrelevant) to 3 (perfect match)
  • Scoring rules:
    • Score 3: Same document (perfect)
    • Score 2: Same policy type (relevant)
    • Score 1: Different policy type (somewhat relevant)
    • Score 0: Not a policy (irrelevant)
def create_ground_truth(query_doc, all_docs): relevance = {} for doc in all_docs: if doc.id == query_doc.id: relevance[doc.id] = 3 # Same doc elif doc.type == query_doc.type: relevance[doc.id] = 2 # Same type else: relevance[doc.id] = 1 # Different return relevance

B Quality Metrics

  • Precision@5: % of top 5 that are relevant (≥2)
  • Recall@5: % of all relevant docs found in top 5
  • NDCG@5: Ranking quality (0-1, higher better)
  • MRR: Position of first relevant result (1/rank)
def precision_at_k(results, ground_truth, k=5): top_k = results[:k] relevant = [1 for doc in top_k if ground_truth[doc] >= 2] return len(relevant) / k def ndcg_at_k(results, ground_truth, k=5): dcg = sum(rel / log2(i+2) for i, doc in enumerate(results[:k]) for rel in [ground_truth[doc]]) ideal = sorted(ground_truth.values(), reverse=True)[:k] idcg = sum(rel / log2(i+2) for i, rel in enumerate(ideal)) return dcg / idcg if idcg > 0 else 0

C Evaluation Process

  • Test queries: 10 random PDF documents
  • For each query:
    • 1. Get top 100 results from database
    • 2. Create ground truth for this query
    • 3. Calculate all 4 metrics
    • 4. Average across all queries
metrics = {"precision": [], "recall": [], "ndcg": [], "mrr": []} for query_doc in random.sample(pdfs, 10): results = search(query_doc, limit=100) truth = create_ground_truth(query_doc, pdfs) metrics["precision"].append( precision_at_k(results, truth) ) # ... calculate other metrics ... # Average all metrics avg_metrics = {k: sum(v)/len(v) for k, v in metrics.items()}
